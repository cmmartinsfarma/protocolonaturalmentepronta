# Protocolo Naturalmente Pronta — Dra. Carolina Martins

Landing page de alta conversão para os protocolos estéticos da **Dra. Carolina Martins** (Farmacêutica Esteta — CRF 125.459).

## 🌸 Sobre o Projeto
Landing page desenvolvida com foco em conversão e captação de leads para os tratamentos de fim de ano:
- **Protocolo Glow ✨**: 7 sessões de gerenciamento de pele.
- **Protocolo Glow & Serenidade 🌙**: 6 sessões de gerenciamento + Toxina Botulínica.
- **Procedimentos Complementares**: Preenchimento Labial, Skinbooster, Secagem de Vasinhos e Gordura Localizada.

## 🚀 Tecnologias
- HTML5 Semântico
- Vanilla CSS com design responsivo, variáveis e animações fluidas
- Integração direta com WhatsApp e Instagram

- Ribeirão Preto / SP
- São Joaquim da Barra / SP
